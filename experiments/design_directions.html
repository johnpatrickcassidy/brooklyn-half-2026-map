Brooklyn Half Marathon - Interactive Map Project

Implementation Plan Overview

Goal: Build a responsive HTML5/Leaflet web application to visualize 19 road closures across Brooklyn.

  • Architecture: Split-screen layout (`index.html`) with left sidebar navigation and right map panel.
  • Data Layer: Structured JSON array (`data.js`) storing segment metadata and approximated coordinate paths.
  • Interactivity: Synchronized state (`app.js`) where sidebar selections auto-zoom the map and trigger informative popups.
  • Status: Baseline functionality has been completed and verified.

Overlay Design Directions

Explore three distinct visual paradigms for rendering the street closures onto the base map. Review the options below and click "Copy Prompt" to extract the implementation instructions for your preferred aesthetic.

Direction 1: Minimalist & Informative

Focuses on crisp visual clarity. Uses clean, semi-transparent primary solid lines to denote closures without overwhelming the underlying map geography. Ideal for general navigation.

Direction 2: Hazard / Construction Tape

Maximizes disruption awareness. Renders custom multi-layered polylines featuring an alternating yellow and black dashed overlay to visually mimic hazard tape. Unmistakable indication of closed routes.

Direction 3: Athletic / Race Day Branding

Injects event energy. Uses official race brand colors (Deep Navy and Vibrant Neon Green) alongside multi-layered glow effects. Provides a premium, custom-branded feel tailored specifically to the marathon event.
